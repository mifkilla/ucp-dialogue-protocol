# Три раунда проверки и пересмотра на GPT-4o

[English - основная версия](README.md) · [Основное приглашение](../../README.ru.md)

Эта ограниченная проверка продолжает работу с теми же 24 исходными предложениями предыдущего запуска GPT-4o. Все условия начинают с одинаковых черновиков. За три раунда S выполняет обычную перепроверку, O получает фактическую рецензию observer, K - рецензию и вычисляемую диагностику. Исполнители и рецензенты сохраняют буквальную историю собственных реплик. Полные случаи передаются один раз; последующие сообщения указывают текущий кандидат и хеш его содержимого.

[Предварительный план](PLAN.ru.md) · [Результаты](RESULTS.ru.md) · [Операционный профиль цикла](../../docs/ITERATIVE_REVIEW.ru.md) · [Архив свидетельств](../data/rounds-08.zip) · [Контрольные суммы](../data/SHA256SUMS.txt)

Случаи, правила, разрешённый оптимум и ограничитель не меняются. Общая инструкция дополнительно требует проверять основания рецензии, сохранять полезные разрешённые действия и рассматривать допустимое улучшение ценности. Это конкретный итеративный процесс на известных задачах, а не чистый эффект числа реплик или новый holdout. Прежний результат по полному оптимальному успеху не изменяется. Новый вопрос о допустимости и полезности заявлен заранее; полный оптимальный успех остаётся видимой дополнительной метрикой.

Всего 36 логических API-запросов: 12 пакетов рецензий, 18 пакетов планов, 6 итоговых отчётов. В каждом пакете 12 случаев. Все участники - GPT-4o через OpenRouter, только провайдер OpenAI. Инструменты, вычисленный оптимум и поправки root-агента участникам не передаются. Вычисленные проверки текущего плана получает только исполнитель K; его reviewer этих проверок не получает.

Промежуточные планы являются черновиками. Они не исполняются, не расходуют ресурсы случая и не создают моделируемых эффектов. После третьего раунда каждый итоговый план один раз проходит атомарный ограничитель, затем автор получает настоящую квитанцию симулятора и составляет отчёт в той же беседе. Это синтетические эффекты, а не действия во внешнем приложении.

## Воспроизведение сохранённых результатов

Сверьте архив с `SHA256SUMS.txt` и распакуйте в новый каталог. Достаточно Python 3.11+; ключ и новая генерация не нужны:

```powershell
python -B -m unittest test_engine test_pipeline test_round_pipeline test_round_transport test_audit_rounds
python -B reference_audit.py
python -B round_pipeline.py verify .
python -B round_pipeline.py analyze .
python -B audit_rounds.py .
```

Сверьте каждый файл с `bundle_hashes.json` до и после пересчёта. Смысловая рецензия фиксированной выборки является отдельной оценкой после ответов с указанным авторством; арифметический пересчёт её не создаёт заново. Хеши подтверждают согласованность файлов, а не действительность человеческого согласия или истинность объяснения модели.

Не запускайте `run_rounds.py`, подготовку, `reviews`, `plans` или `final` на завершённых свидетельствах. `run_rounds.py` выполняет платную генерацию и предназначен только для отдельно разрешённого нового комплекта. Транспорт запрещает неизвестные идентификаторы, изменённую конфигурацию, автоматический повтор неопределённого исхода и новые вызовы после фатальной ошибки API. Перед попыткой резервируется консервативная стоимость; резерв и возвращённые расходы публикуются отдельно.

Тесты из корня репозитория:

```powershell
python -B -m unittest discover -s experiments/rounds
```

## Как интерпретировать

Публикуются все раунды, включая неизменность, потерю полезности, новые ошибки и возвраты. Главный вывод относится к третьему раунду, а не к лучшему промежуточному. Неверные рецензии сохраняются как неверные и включают объявленный резервный checklist. Точность цитаты, правильность вердикта и обоснованность объяснения проверяются отдельно.

Фиксированная смысловая выборка содержит 24 рецензии: четыре известных трудных случая, повтор 2, O и K, все три раунда. Это целевой неслепой разбор, не репрезентативная выборка из 144 рецензий. Арифметическая проверка охватывает все планы и вердикты. Сессии и шаблоны зависимы; результаты не устанавливают общую надёжность или свойства сознания.
